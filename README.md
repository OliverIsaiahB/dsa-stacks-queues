# Stacks & Queues

A from-scratch beginner project that turns two of the most common interview data structures into things you have built with your own hands. You implement a stack and a queue from first principles, learn why a naive list-based queue is secretly O(n) and how a deque fixes it, then build the heavy hitters interviewers actually ask about — balanced-parentheses checking, an expression evaluator, the monotonic stack, and a queue-driven BFS scaffold. Throughout, the Socratic dialogue teaches the WHY and the Big-O: why LIFO and FIFO map to different problems, why amortized O(1) is the precise claim, and how the same queue machinery powers breadth-first search.

Built step-by-step with [KhwajaLabs Build](https://khwajalabs.com).
